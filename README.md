# PETSY

Personalized pet universe: upload once, own the character, monetize across
cards, figures, video, AR. One pet mesh feeds every SKU. Zero inventory.

Start: `VISION.md` (thesis) → `STACK.md` (locked SKUs, margins, suppliers) →
`docs/` (build specs). Ideas incubate in `ideas.md`; graduate to `docs/products.md`
or die with a reason.
