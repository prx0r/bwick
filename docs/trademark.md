# Trademark triage (2026-09-25)

Rule: sell the genre, never the character. "Dark academy uniform figure" ranks;
"Gojo figure" gets delisted (plus risks the whole shop via VeRO).

## Green (archetype, safe)

Wizard academy, pirate crews (straw hats are generic — just never say the words),
soldier/slayer-corps uniforms, capes, swords, owls, castles. Genres, not properties.
Cottagecore/goblincore, Y2K, block-builder aesthetics. Idol-*stage* aesthetics
(lightsticks, stage outfits, photocard format) without real people.

## Yellow (evocative, handle with care)

- Demon Slayer's green-black checkered haori reads as Tanjiro with no name
  attached — use check patterns in other colorways.
- "Cursed energy effects," "hunter ranks" — vibes and systems, not ownable. Fine.
- "Straw-hat-coded" pushed too far becomes the character. One straw accessory =
  genre; full outfit + scar + red vest = the pirate. Know where the line bends.

## Red (don't)

Character names, direct likenesses, quoted attacks/techniques, logo-ish motifs,
series titles in titles/tags/descriptions. **K-pop idol figures of real people:
likeness rights, separate minefield from copyright** — stage aesthetics only,
never a real person's face as a product.

## Mesh sourcing (hybrid — verified pattern)

- Never rip random models (copyright attaches to the file; competitors report).
- Meshy's free-model gallery (CC0-claimed) for bases, props, stands — verify
  license per model before commercial use; terms vary by upload.
- The system: one clean in-house base body per style (brick man/woman/pet, chibi
  equivalents — modeled once, properly) + AI texture/face pass per order. Bases
  amortize to zero; per-order work stays generative; quality stays consistent
  instead of re-rolling anatomy every order.
