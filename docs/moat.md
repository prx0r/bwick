# Moat — cast, don't copy (2026-09-25)

**Everyone else copies your photo. We cast you in a world.**

Competitors sell accuracy ("matches your hair, outfit, glasses"). We sell
transformation: upload a selfie, come back a wizard cadet / starship ensign /
ringside cornerman. Accuracy is table stakes; belonging is the product. Nobody
else sells it because human designers match photos — they don't art-direct
universes. The theme system does it per prompt-flag.

## Consequences

1. **Marketing writes itself.** Before/after hits different when the "after" is
   a world, not a minifig: "Send a selfie. Enlist in Starfleet." Every theme is
   its own ad creative, TikTok series, listing cluster.
2. **The style picker becomes the product page.** Not "choose colors" —
   "choose your world." Each world = listing cluster + content series +
   seasonal re-skin.
3. **Premium justified.** Matching a photo is a $22 commodity. Casting someone
   into a universe (posed scene, props, in-character roast) is a $60+
   experience. The world is what the extra $40 buys.

## Worlds (launch set + rotation)

- Wizard Academy, Starship Crew, Fight Night, Racing Paddock, Arena Tribute.
- Seasonal skins rotate quarterly on the same worlds. New world = new listing
  cluster, never a new pipeline.
