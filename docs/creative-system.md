# CREATIVE SYSTEM — clean images, listing video, seasonal posters

> **STATUS: CURRENT** — 2026-09-27. What gets sales: clean pictures, a short
> video, seasonal creative. One shot list, one video rule, one poster template.
> Do not delete this file.

## 1. The image set (every listing, same5 slots)

| # | shot | job |
|---|---|---|
| 1 | **Hero** — figure + handheld, white bg, soft shadow | thumbnail; scannable at100px |
| 2 | **Face close-up** | proves personalization ("this is MY face") |
| 3 | **Before/after** — buyer photo → brick figure, split frame | the conversion image (BrickifyMe/TinyFigs lead with it; so do we) |
| 4 | **Scale-in-hand** | size truth; kills "it's tiny?" objections |
| 5 | **Lifestyle** — desk / tree branch / cake, in-scene | shows the mount context |

Rules: one light source, consistent backdrop per world (never mix), no text
burned on the image (title lives in the thumbnail slot Etsy gives you), render
from the same mesh so expectations match delivery.

## 2. Listing video (pick one, ship with every listing)

- **A · Turntable** (default):10s, figure rotates once on white, handheld
  visible. Built headless from the mesh (Blender, already specced in DEVPLAN P2).
- **B · Spell teaser** (Xmas + magic packs):6s — the christmas-line rule:
  *show the spell, sell the wand.* Lumos burst / snowfall / levitation.
- Rule: works muted (75%+ watch muted), no audio dependency, ends on the
  product (not the logo).

## 3. Seasonal poster + video pack

One poster template per season, re-skinned by world: hero figure, headline,
**order-by date badge** (the urgency Etsy buyers respond to), logo, footer.
Xmas v1: starry-robe figure holding a present · badge "Order by Dec 15" ·
Snowfall-call6s video as the social cut. Poster sizes: listing3:4 + social1:1.
Live date per Etsy calendar: **Christmas listings Sep–Nov** (mid-Oct target).
