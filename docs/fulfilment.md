## The box (v1)

| | **S — single figure** | **M — couple set** |
|---|---|---|
| Outer | plain kraft mailer ≈12×9×9cm | plain kraft mailer ≈18×12×10cm |
| Seal | **logo sticker** on flap | same (two if it helps) |
| Inside | **thank-you card** — front: thanks + world name; **back: QR** → their talking video | one card per figure |

- **One artwork file** (sticker + card), mailed to both providers as pack-ins.
  Makr3D packs inserts into every order; 3D Vikings stores and adds yours.
- **No printed boxes, no MOQ, no lead-time deadlines.** Branded boxes exist
  (Vikings: MOQ100,10-day, €0.28–2.06) — a2027 question, not a Xmas one.
- **Name personalisation prints at source**: both providers accept variant data
  (names, numbers, freeform text) flowing from the store into the print — the
  plinth carries the name, no manual labelling.
- **Mounts are print parts**: plinth (desk), loop (tree ornament), spike (cake
  topper), magnet, ring — same figure, different base, different listing.
