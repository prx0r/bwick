# BSWITCH — tarot / mystic / witchy collection (2026-09-25)

Third skin of the Bwick system. **Same core, different filter** — that's the
whole spec. Siblings: `bwizards.md`, `bwickmas.md`.

## The filter principle (what's shared vs what changes)

| Shared (build once) | Changes per skin |
|---|---|
| 5 products (dog / cat / solo / couple / family+pet) | Theme fragment (Meshy texture_prompt) |
| Base system (single base + couple base) | Backplate artwork (interchangeable panel, not a new 3D model) |
| Mount library (socket/spike/loop/plinth/magnet/ring) | Prop set (2–3 meshes) |
| One pipeline, one QA bar, one print profile | Palette |
| AR binding layer (UUID → pet → moment) | Copy tone + occasion |
| Pricing math (30% net, ship absorbed) | AR effect |
| Trademark gate, approve-before-print | Shop section + listing cluster |

No new pipeline, no new base, no new QA. A skin is: fragment + panel + 3 props +
palette + copy. Roughly an afternoon each.

## Bswitch specifics

- **Palette**: indigo + violet + moon silver + candle flame (nighttime, against
  bwizards' daytime navy/gold/parchment).
- **Frame**: tarot card frame — image area, title banner, roman numeral, keyword
  line. One layout serves card, backplate, sticker, poster.
- **Props**: crystals, raven, crescent moon, cauldron, candle, tarot deck in hand.
- **Copy tone**: archetype, not roast. Meaning > joke. Still funny-adjacent
  (pet tarot can be deadpan), never mystical-pseudo-serious.
- **AR effect**: card-flip reveal → glow/stars → title + names.

## Products

1. **"The Lovers" couple display** — archetypal couple, names + date on base.
   QR: step together → glow → title. Variants: any pairing, couple+pet.
   **£49–59.** Anniversary / wedding / Valentine's. Top priority.
2. **Pet tarot** — pet gets a *role*, not a costume. Figure **£15–25**,
   card **£4–6**, ornament, sticker. Best pet SKU in the system.
3. **"The Magician" solo** — archetype with props, semi-custom title. **£25–35.**
   Birthday / self-gift / spiritual buyers.
4. **"Your Card" archetype birthday** — recipient picks the arcana. Removes
   design paralysis; cleanest order flow we own.
5. **Trading card add-on** — 2.5×3.5" 18pt, archetype face. Cheap basket-stuffer;
   future deck (22 archetypes + couple/pet expansions).

**Cats**: Tabby → **The Hermit** · Black cat → **The Moon** ·
Orange menace → **The Fool** · Siamese → **The High Priestess** ·
Maine Coon → **The Emperor**

Defaults if no breed given: dog → The Sun, cat → The Moon. Customer can pick
any archetype in the 5 text boxes ("archetype: The Hermit").

## Legal (non-negotiable)

- Archetype names (The Lovers, The Magician) = generic card terms, safe.
- **No Rider-Waite art.** Original 1909 plates are US-public-domain but copying
  is an attribution/trademark mess and isn't our look. Draw in house style.
- **No Thoth** (Crowley/Harris, still copyrighted). No "Rider-Waite" in copy.
- Scan titles/tags via `trademark.md` before listing.
