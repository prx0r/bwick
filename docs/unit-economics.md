## Bundle (the margin play): card + figure + stickers + video

£29.99 + £5.00 + £3.00 + £5.00 = £42.99 basket (example).
COGS: figure £2.50 + card £1.10 + stickers £0.50 + video £0 + mesh £0.15
= ~£4.25 + combined ship ~£4.50 + fees ~£5.90 → **net ~£28 (~66%)** on one parcel.
Bundling one shipment across SKUs is where POD margins go silly — always attach.

## Lead-time promises (publish in listings)

- Cards/flat (Prodigi): production 2–5d + ship 1–3d → promise 5–8 working days.
- Figures (Makr3D): dispatch 1–2d + ship 2–3d → promise 3–5 working days.
- Digital: instant (deliver on order notification).
- December: publish order cut-offs early; auto-fulfil protects Star Seller ship times.

## Caveats (do not list blind)

- Prodigi per-SKU ship costs vary by size — quote each SKU (free, instant).
- Makr3D multi-colour purge = human quote (start single/two-tone).
- EN71 sits with us (position figures as collectibles, not toys).
- Offsite ads (12–15%) would shave ~£1–8/order if enrolled — model above excludes it.
- VAT: Makr3D figures ex-VAT shown; reclaim if VAT-registered.
