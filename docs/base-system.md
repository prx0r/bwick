# Base system — one socket, five mounts (2026-09-25)

The figurine never changes; it plugs into mounts. One pipeline, one QA bar,
one print profile. New context = new base file, never a new figure.

## The socket (standard, every figure)

Single peg pocket on every figure base (sized for 3mm peg, 8mm deep — confirm
in CAD before first print). All mounts carry the mating peg. Tolerance tested
on the sample print before listing anything.

## The five mounts (10p accessories, five price points)

| Mount | Build | Price context | Rule |
|---|---|---|---|
| Spike pick | food-safe spike (only the pick touches cake) | topper £60–80 set | NEVER stick raw PLA directly in food — state this, buyers notice |
| Ribbon loop cap | screw-loop / slotted cap, peg in | ornament £35 | + ribbon + gift box |
| Name plinth | embossed in-slicer (free) | desk £25 | name + date on plinth face |
| Magnet disc | flat back + neodymium recess | magnet £15 | disc glued post-print (not printed-in) |
| Loop cap + ring | loop cap + split ring | keychain £8–12 | entry/review engine |

## Food-safety rule (non-negotiable, stated in listings)

Only the spike touches cake. Raw PLA never contacts food. State it — buyers
notice and it pre-kills the #1 safety question.

## What this kills

Six "products" of complexity: one figure file, one QA check, one Makr3D
profile. Merchandising (mount + box + story + price) does the rest. New
context = draw a base, never rebuild the animal.
